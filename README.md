## 🌌 نظرة عامة (Overview)

**مصفوفة الإثبات الطوبولوجي للأنسجة (v32.0 - Proof Level)** هي بيئة محاكاة فيزيائية-طوبولوجية تفاعلية ثلاثية الأبعاد مبنية باستخدام **Three.js** ومحرّك شيدر مخصص (**GLSL Custom Shaders**). يهدف النظام إلى دراسة ونمذجة التداخل الرياضي بين مصفوفات الوعي المنظم (الممثلة عبر لوحات فنية أو أنسجة بيولوجية/كسيرية محقونة) وشبكة المادة المظلمة الهندسية تحت تأثير ضغط التشويه الكسيري والترددات الاهتزازية في الزمن الحقيقي.

النظام مجهز بأدوات قياس تجريبية حية (Empirical Telemetry)، وسجل برهان مشفر (Empirical Ledger)، ونظام توثيق وتصدير فيديو مباشر من بطاقة الرسوميات، إلى جانب مذبذب صوتي توافقي مبني على تردد الرنين الكوني (432Hz).

## 📐 المعادلات الرياضية والفيزيائية (Mathematical Formulation)

يعتمد المحاكي على مجموعة من الخوارزميات الدقيقة المطبقة مباشرة داخل بطاقة الرسوميات (GPU):

### 1. إزاحة السطح التموجية في الـ Vertex Shader
تُحسب إزاحة كل رأس هندسي $p = (x, y, z)$ على طول المتجه العمودي الناظم $N$ بناءً على شدة الضغط الكسيري $D$ وتردد المصفوفة $\omega$ والزمن $t$:

$$\Delta p = \left[ \sin(p_x \cdot \omega + t)\cos(p_y \cdot \omega + t) + \sin(p_y \cdot \omega - t)\cos(p_z \cdot \omega + t) + \sin(p_z \cdot \omega + t)\cos(p_x \cdot \omega - t) \right] \cdot 0.15 \cdot D$$

الموضع النهائي للرأس:
$$P_{final} = P + N \cdot \Delta p$$

### 2. معامل التداخل الطيفي (Interference Factor)
في الـ Fragment Shader، يتم دمج تدرج ألوان المادة المظلمة مع النسيج المحقون $T(u, v)$ وفق دالة تداخل موجي:

$$I(t, \Delta p) = 0.4 + 0.3 \cdot \sin(t + \Delta p)$$

$$C_{final} = \text{mix}(T_{rgb}, C_{base}, I) \cdot L + C_{accent} \cdot \text{Fresnel}$$

### 3. مؤشرات الإثبات التجريبية (Empirical Metrics)
* **معامل التداخل البنيوي ($I$):**
  $$I = \text{clamp}\left(62 + 16 \sin(1.5t) + 5.2 D, \ 0, \ 100\right)\%$$
* **رنين الضغط الطيفي ($R$):**
  $$R = 1.0 + (D \cdot \omega) \cdot 0.125$$
* **تغير الإنتروبيا الحركية ($\Delta S$):**
  $$\Delta S = |\cos(0.6t)| \cdot 0.024 + 0.0055 D$$
* **مويجة الانحناء الطوبولوجي ($K$):**
  $$K = 1.0 + 0.25 D \cdot \sin(0.8t)$$

## 🛠️ الخصائص والمميزات الرئيسية (Core Features)

### 1. حقن النسيج البصري (Texture Injection)
* **رفع الصور المخصصة:** إمكانية رفع أي لوحة فنية أو صورة مجهرية من جهاز المستخدم لحقنها في المصفوفة ودراسة تداخلها.
* **5 أنسجة وعي تركيبية جاهزة بدقة 1024×1024 (Zero-Dependency Procedural):**
  1. **نسيج الوعي العصبي البيولوجي (Neural):** شبكة خلايا سينابسية ومسارات عصبية متوهجة.
  2. **مصفوفة الهندسة المقدسة (Sacred):** زهرة الحياة وتناغم دوائر النسبة الذهبية.
  3. **سديم الانفرادية الكمومية (Cosmic):** دوامات الجاذبية المظلمة وجزيئات الغبار النجمي.
  4. **شبكة البيانات السيبرانية (Cyber):** مصفوفة سداسية فائقة التوصيل مع مسارات ضوئية.
  5. **التدفق اللوني الطيفي (Chromatic):** أمواج ليزرية متداخلة بألوان قزحية متغيرة.

### 2. القوالب الهندسية المتكيفة (Adaptive Geometries)
* **قالب كروي متزن (Sphere Geometry):** توزيع شبكي منتظم للموجات المتوازنة.
* **قالب صندوقي اختباري (Box Geometry):** لدراسة التشويه على الحواف والزوايا الحادة.
* **طارة طوبولوجية (Torus Topology):** تمثيل الفضاء الحلقي المغلق.
* **عقدة كسيرية (Torus Knot):** تشابك هندسي معقد متعدد الأبعاد.
* **عشروني السطوح (Icosahedron):** تجسيم بلوري ذو 20 وجهاً كمومياً.
* **أسطوانة الزمكان (Spacetime Cylinder):** أبعاد طولية لدراسة التمدد الرأسي.

### 3. أبعاد لوحة العرض وحالات الشيدر
* **منزلقات التمدد الثلاثي:** تحكم دقيق في الأبعاد $X, Y, Z$ من 0.4 إلى 2.5.
* **أوضاع الرندرة (Render Modes):**
  * **هيكل شبكي (Wireframe):** فحص المادة الخام وبنية الخطوط الطوبولوجية.
  * **تجسيد مصمت (Solid):** التحام كامل وتفاعل تظليلي مع النسيج.
  * **سحابة نقاط كمومية (Quantum Points):** تفكيك النموذج إلى ذرات نقطية عائمة.
  * **توهج هولوغرافي شفاف (Holographic Glow):** شفافية إشعاعية بنمط Additive Blending.
* **لوحات الألوان النيونية (Color Palettes):**
  * النيون السيبراني (Neon Cyber): فيروزي `#00f2fe` + بنفسجي `#9d4edd` + وردي نيون `#ff007f`.
  * الزمرد الكمومي (Quantum Emerald): زمردي أخضر + أزرق سماوي + ذهبي.
  * الفراغ الكوني (Cosmic Void): أرجواني عميق + ماجنتا + أزرق كوني.
  * البلازما الشمسية (Solar Plasma): برتقالي شمسي + قرمزي + أصفر كهرماني.

### 4. أوامر المعايرة والحقن الفوري (Instant Calibration)
* **مصفوفة كسيرية حرجة (HYPER_FRACTAL):** تردد 7.0Hz وضغط تشويه 4.5 لأقصى اضطراب طيفي.
* **تدفق بيولوجي مرن (FLUID_MATRIX):** تردد 1.5Hz وضغط 1.8 لمحاكاة النبض العضوي.
* **رنين كمومي فائق (QUANTUM_RESONANCE):** تردد 5.2Hz وضغط 2.8 لأعلى توافق هارموني.
* **توازن كوني مستقر (COSMIC_EQUILIBRIUM):** تردد $\pi$ وضغط 1.2 لحالة الاستقرار الهندسي.
* **إعادة ضبط النواة (RESET):** إعادة المعاملات للقالب المعياري المتزن.

### 5. التوثيق والتصدير الفوري (Export & Capture Tools)
* **تصدير إثبات مصفوفة الحقيقة © (Video Export):** تسجيل فيديو حي بصيغة `.webm` بدقة الكانفاس كاملة عبر `MediaRecorder` و `captureStream` مع مؤقت زمني وتنزيل تلقائي.
* **لقطة إثبات (Snapshot):** التقاط فوري لقطة شاشة بدقة فائقة كملف `.png`.
* **سجل البرهان والأشكال (Empirical Ledger):** سجل تدقيق علمي مع ترقيم العقد وتصنيف الأحداث، مع إمكانية التصدير كملف تقرير نصي (`.txt`) أو كبيانات مهيكلة (`.json`).

### 6. الصوت التوافقي الكوني (Cosmic Drone Synthesizer)
* مذبذب تركيبي صوتي مبني على **Web Audio API** بدون أي ملفات خارجية.
* يولد نغمة أساسية متوافقة مع التردد الطبيعي (432Hz harmonics / 108Hz base) مع طبقة خامسة وطبقة sub-bass.
* يتفاعل مرشح الترددات المنخفضة (Low-pass Filter) ديناميكياً مع معاملات الضغط والتشويه والتردد في المحاكاة في الزمن الحقيقي.

### 7. واجهة ثنائية اللغة وتجربة سينمائية
* واجهة عربية أصيلة مع دعم تبديل فوري للغة الإنجليزية بنقرة واحدة (`AR / EN`).
* خط عربي محلي مدمج عالي الدقة (Noto Sans Arabic) يضمن خلو العرض من أي تشوهات نصية.
* **وضع الشاشة السينمائية الخالصة (Zen Mode):** إخفاء كافة لوحات التحكم بضغطة زر أو عبر مفتاح الاختصار `H` للتأمل والمراقبة الكاملة للمصفوفة.

## 🚀 دليل التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات الأساسية
* **Node.js** (الإصدار 18 أو أحدث)
* **npm** أو **pnpm** أو **yarn**

### خطوات التشغيل
1. استنساخ المستودع أو فتح المجلد:
   ```bash
   cd /workspace
   ```
2. تثبيت الحزم البرمجية:
   ```bash
   npm install
   ```
3. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على العنوان: `http://localhost:3000`

### بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```
